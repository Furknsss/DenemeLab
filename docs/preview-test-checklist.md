# DenemeLab — Android önizleme test kontrol listesi

Bu sürüm yalnızca görsel iskelettir; aşağıdaki testler Android cihazda manuel kontrol içindir.

- [ ] Ana sayfa, denemeler, analiz ve hesabım sekmeleri arasında geçiş yapılabiliyor
- [ ] Ekranlar küçük telefonda ve tablette kaydırılabiliyor
- [ ] PDF seçici açılıyor, PDF seçildiğinde dosya adı denemeler sayfasında görünüyor
- [ ] Tüm istatistiklerin örnek veri olduğuna ilişkin uyarılar görünüyor
- [ ] SoruLab kurulu cihazda DenemeLab ayrı bir uygulama olarak kurulabiliyor

### APK
GitHub Actions → Android preview APK → başarılı çalıştırma → Artifacts → DenemeLab-Android-Preview-APK.
